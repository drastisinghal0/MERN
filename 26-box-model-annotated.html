Box Size Calculation

Property Calculation
Total Width 200 + (20×2) + (10×2) = 260px
Including margins = 320px
Total Height 80 + (20×2) + (10×2) = 140px
Including margins = 200px

Using box-sizing:border-box

When box-sizing:border-box is applied, the width and height include the padding and border. Therefore, the total width remains 200px and the content area becomes smaller.

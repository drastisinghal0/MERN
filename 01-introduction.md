# Assignment 1 – What happens between typing a URL and seeing the page?

## Question
What happens between typing a URL and seeing the page?

## Answer
1. Browser checks cache.
2. DNS converts domain name into IP address.
3. Browser connects to the server.
4. Sends an HTTP request.
5. Server sends the response.
6. Browser downloads HTML, CSS, and JavaScript.
7. The page is rendered on the screen.
